# Supermarket Sales Analytics Dashboard

## 📊 Overview
This interactive Excel dashboard analyzes supermarket sales data to track key performance metrics, monthly trends, and product performance insights.

## 🔑 Key Features & Insights
- **Key Metrics (KPIs):** Total Revenue, Total Orders, and Average Bill Value.
- **Sales Analysis:** Category-wise sales breakdown, Top 5 products by revenue, and day-wise sales distribution.
- **Interactive Controls:** Slicers for filtering data seamlessly by Month and Product Category.

## 🛠️ Tools Used
- **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, Data Analysis.
