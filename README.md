# Supermarket Sales Analytics Dashboard

## 📊 Overview
This interactive Excel dashboard analyzes supermarket sales data to track key performance metrics, monthly trends, and product performance insights.

## 🔑 Key Features & Insights
- **Key Performance Indicators (KPIs):** Instant view of Total Revenue, Total Orders, and Average Bill Value.
- **Category & Product Analysis:** Detailed breakdown of sales by product categories and Top 5 performing products.
- **Monthly & Day-Wise Trends:** Visual trend analysis across months and days of the week to identify peak sales periods.
- **Interactive Slicers:** Dynamic filters for Month and Category to dive deep into specific datasets.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, Data Cleansing, & Custom Dashboard Design.

## 📂 Step-by-Step Guide to Access
1. **Download:** Click on `Supermarket_Sales_Analytics_dashboard.xlsx` in this repository and download the file.
2. **Open in Excel:** Open the file using Microsoft Excel (2016 or newer recommended).
3. **Interact:** Use the slicers on the left side of the dashboard to filter sales data by month or category dynamically.
